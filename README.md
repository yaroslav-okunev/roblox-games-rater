# Roblox Games Rater

A tiny Flask web app.

## Project Structure

- `src/app.py` starts the web server.
- `src/templates/games.html` is the page HTML.
- `src/static/styles.css` controls the page style.
- `docs/` is for project documentation.

## Run It

Create a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install Flask:

```bash
pip install -r requirements.txt
```

Start the app:

```bash
python src/app.py
```

Open the local address shown in the terminal, usually:

```text
http://127.0.0.1:5000
```
